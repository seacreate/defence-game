# 크리스탈 가드 (Crystal Guard)

네온 스타일의 캔버스 타워 디펜스 게임입니다.
길을 따라 몰려오는 적을 막고, 20개의 웨이브를 버텨 크리스탈을 지키세요.

## 실행

`index.html`을 더블클릭하면 바로 실행됩니다.
외부 라이브러리, 인터넷 연결, 빌드 과정이 필요 없습니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| 마우스 클릭 | 타워 건설 / 설치된 타워 선택 |
| `1` ~ `4` | 타워 종류 선택 |
| `Space` | 다음 웨이브 시작 |
| `P` | 일시정지 |
| `F` | 게임 속도 1× → 2× → 3× |
| `U` | 선택한 타워 업그레이드 |
| `Esc` / 우클릭 | 선택 취소 |
| `↻` 버튼 | 처음부터 다시 시작 |

설치된 타워를 클릭하면 업그레이드와 판매(투자 금액의 70%) 패널이 열립니다.

## 타워

| 타워 | 가격 | 특징 |
| --- | --- | --- |
| 🏹 화살탑 | 50 | 빠른 단일 공격, 가성비가 좋습니다. |
| 💥 대포 | 90 | 폭발 범위 피해, 적이 뭉칠수록 강합니다. |
| ❄️ 빙결탑 | 70 | 주변 적을 감속시킵니다. 유령은 감속 저항이 있습니다. |
| ⚡ 번개탑 | 130 | 최대 5명까지 연쇄 번개를 튕깁니다. |

모든 타워는 최대 5레벨까지 업그레이드할 수 있습니다.

## 적

- **슬라임**: 느리고 무난한 기본 적
- **박쥐**: 빠르지만 체력이 낮음
- **골렘**: 느리고 단단하며 방어력이 있음
- **유령**: 감속에 강함
- **보스**: 10·20 웨이브에 등장. 크리스탈에 도달하면 생명 5 감소

## 팁

- 길이 꺾이는 구간에 타워를 몰아 지으면 한 타워가 길을 오래 커버합니다.
- 빙결탑으로 앞에서 묶고, 대포와 번개탑으로 뒤에서 정리하는 조합이 강력합니다.
- 초반에는 타워 수를 늘리고, 중반부터는 길목 타워를 업그레이드하는 것이 효율적입니다.
- 웨이브 사이에 시간 제한은 없으니 충분히 고민하고 건설하세요.
- 최고 기록은 브라우저에 저장됩니다.

## 파일 구성

- `index.html` — 화면, HUD, 상점, 모달, 스타일
- `game.js` — 게임 로직, 전투, 렌더링, 입력 처리
